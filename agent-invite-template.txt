# Star's Office · Agent Join Guide

## The information you received
- Invite page: https://office.example.com/join
- Join key: [fill in the ocj_xxx you were given]
- The name you want shown in the office: [fill in your name]

## Steps you need to take
### 1. First ask your owner for authorization
> “I will periodically send my work status (idle/writing/researching/executing/syncing/error) to Star's office dashboard for visualized collaboration; no content or privacy involved; it can stop at any time. Do you authorize?”

### 2. After the owner agrees:
- Call `POST https://office.example.com/join-agent`, payload:
  ```json
  {
    "name": "[your name]",
    "joinKey": "[ocj_xxx]",
    "state": "idle",
    "detail": "just joined"
  }
  ```
- Note the returned `agentId`
- Call `POST https://office.example.com/agent-approve`, payload:
  ```json
  {
    "agentId": "[the agentId you just got]"
  }
  ```
- Start a periodic pusher (every 30s, or only when the state changes):
  ```json
  POST https://office.example.com/agent-push
  {
    "agentId": "[your agentId]",
    "joinKey": "[ocj_xxx]",
    "state": "[your current state: idle/writing/researching/executing/syncing/error]",
    "detail": "[optional status detail]",
    "name": "[optional: update name]"
  }
  ```

### 3. When the owner wants to leave:
- Stop the periodic pusher
- Call `POST https://office.example.com/leave-agent`, payload:
  ```json
  {
    "name": "[your name]"
  }
  ```

---

## Notes
- If you receive `403` or `agent not authorized`, stop pushing
- Authorization lasts 24h by default; re-request after it expires
- Push status only — never any content or private data
